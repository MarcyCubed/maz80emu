# Marcy's Amazing Z80 Emulator!

This is the amazing Marcy's amazing Z80 emulator of amazingness!!

Seriously now, this is just an emulator for the Z80 8-bit processor written in Rust. It tries to be as minimalistic as possible, so all it does is processor stuff. Specifically, it doesn't bother handling memory or I/O. Not even a 64 Kb array for memory. Everything that isn't the processor is up to the user.

This shouldn't be too hard to use and people can implement whatever memory and I/O weirdness they want.

## Why another Z80 emulator?

Why not? I'm writing this to learn how a real processor works. If it's just for me, it's fine. If it's useful for someone else, awesome!
